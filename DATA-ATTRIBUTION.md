# Data and image attribution

## Arcanum Prompt Injection Taxonomy

`docs/data/taxonomy.json` contains taxonomy material adapted from the [Arcanum Prompt Injection Taxonomy](https://github.com/Arcanum-Sec/arc_pi_taxonomy), created by Jason Haddix and Arcanum Information Security.

**Attribution:** Based on the Arcanum Prompt Injection Taxonomy by Jason Haddix, Arcanum Information Security. Source release: v1.6.1. Source repository snapshot used: commit `e02cf5b` (2026-06-29). Licensed under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/), also called CC BY 4.0.

Suggested citation: Haddix, J. (2026). *Arcanum Prompt Injection Taxonomy* (v1.6.1). Arcanum Information Security. <https://www.arcanum-sec.com/pitax>

The Zeroth Index browser and path builder are independent code. The path builder lets a user compose an analyst hypothesis; it does not represent a validated relationship in the source taxonomy.

## Motion clip

“ESOcast 200 Light” by the European Southern Observatory, 2019, is included under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/): [Wikimedia Commons source page](https://commons.wikimedia.org/wiki/File:ESOcast_200_Light.webm). The clip depicts Gaia crossing the sky during observations for a three-dimensional map of the Milky Way. It is user-controlled and does not autoplay.
